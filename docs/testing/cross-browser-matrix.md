## Known risks & mitigations (code-reviewed)

| Risk | Where | Mitigation |
|---|---|---|
| `backdrop-filter` needs `-webkit-` in Safari < 18 | globals.css `.glass-morphism`, `.modal-overlay` | **Fixed Task 4.6** — added `-webkit-backdrop-filter` |
| Tailwind `backdrop-blur-*` utilities | Navbar, Modal, GlassMorphism | PostCSS autoprefixer emits `-webkit-` (default Tailwind v3) — verified |
| CSS custom properties (`var(--*)`) | Entire design system | Supported all modern browsers since 2020 (CSS Variables Baseline 2022) |
| `aspect-ratio` (ProductCard image) | ProductCard, ProductGrid | Supported Safari 15+, Firefox 89+ |
| `scroll-snap` (related products carousel) | Product detail related section | Supported Safari 14.1+; graceful degradation (no snap = normal scroll) |
| `overscroll-behavior`, `position: sticky` | Headers, sticky toolbars | Widespread support; sticky works on all modern browsers |
| Framer Motion `transform` animations | Navbar, cards, modals | Transform/opacity only after Task 4.5 audit (12 layout animations converted) |
| `backdrop-blur` unavailable in older Firefox | — | FF 103+ (2022) — below supported baseline |

## Visual regression

- **Spec:** `e2e/visual.spec.ts` — 16 pages × 3 viewports (mobile 375, tablet 768, desktop 1280), animations disabled, full-page screenshots, console-error assertions
- **Generate baselines:**
  ```bash
  npx playwright test e2e/visual.spec.ts --update-snapshots
  git add e2e/visual.spec.ts-snapshots/
  ```
- **Run comparison:**
  ```bash
  npx playwright test e2e/visual.spec.ts
  ```
- **Caveat:** Auth-guarded pages (`/profile`, `/orders`, `/checkout`, `/admin/*`) redirect to `/login` when logged out — screenshots capture the redirect target. Add a `storageState` fixture to capture real content.
- **Browser availability:** This task was executed without installed Playwright browsers in the sandbox (no `npx playwright install` run). Baselines must be generated by the maintainer on a machine with browsers installed.

## Manual testing checklist (recommended before release)
